# starter-pack

A personal Claude Code plugin marketplace. It encodes how its owner wants Claude to work: house rules learned from months of sessions, guard hooks that enforce the mechanical ones, a project kickoff that prepares cloud handoffs, and stack, design, engineering and SRE skills for a TypeScript + Python agentic stack.

> Work in progress. The full README lands with the first complete release.

## Install

```text
/plugin marketplace add sanath1599/claude-workbench
/plugin install workbench@starter-pack
/workbench:setup
```

The repository is private. Claude Code clones it with your git credentials (`gh auth setup-git` once if HTTPS cloning asks for a password).
