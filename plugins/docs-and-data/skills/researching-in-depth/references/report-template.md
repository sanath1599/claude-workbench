# Report template

Save as `reports/<short-title>.md`, or as one self-contained HTML file when the report is for sharing.

```markdown
# <Specific title: the question, not the topic>

As of <date>. Prepared for <decision or reader>.

## Answer
<Two to four sentences. The recommendation or conclusion, then the confidence
(high, medium, low) and the one thing that would change it.>

## Why
1. <Reason, with the number or fact> [3][7]
2. <Reason> [2]
3. <Reason> [5]

## Comparison (when options are compared)
| Criterion | Option A | Option B | Source |
|---|---|---|---|
| Cost per month | ... | ... | [4][6] |

## What the sources disagree on
- <Point>: <source A says X [2]>, <source B says Y [8]>. <Which you trust and why.>

## What is not known
- <Question that sources did not answer, and how to find out>

## Method
<Threads run, date range searched, source types preferred, anything excluded.>

## Sources
| # | Title | Publisher | URL | Date | Type and reliability |
|---|---|---|---|---|---|
| 1 | ... | ... | ... | 2026-10-03 | primary, official docs |
```

## Source reliability labels

| Label | Meaning |
|---|---|
| primary | the standard, law, filing, dataset or original paper itself |
| official docs | the maintainer's own documentation |
| independent | a third party with no stake and a method you can read |
| vendor claim | a seller describing its own product |
| opinion | a person's view without evidence |
| undated | cannot say when it was true; use only to support, never to decide |

## Citation rules

- Number sources in order of first use. One claim, one or two citations.
- A quotation is exact and short, with the page or section.
- If a source was paywalled or failed to load, log it as "not read", and do not cite its contents.
